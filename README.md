批量保存网页为 HTML（富文本识别增强版）

本压缩包包含两个浏览器扩展版本：
- chrome-edge：适用于 Google Chrome / Microsoft Edge
- firefox：适用于 Mozilla Firefox

本次改进
1. 富文本编辑器可直接粘贴网页前台列表，读取标题背后的真实 <a href>。
2. 增加独立 HTML 源码输入框；支持普通源码和实体转义后的源码（如 &lt;a href=...&gt;）。
3. 支持 Markdown 链接、纯 URL 列表、相对文章地址、href/data-href/data-url 属性。
4. 可设置相对链接基准网址、域名筛选、仅保留 .html 文章链接、排除媒体/静态资源和去重。
5. 结果默认全选，可逐项取消勾选，并复制链接或导出 TXT。
6. 仅对勾选的链接批量加载页面并保存 HTML；可设置每批数量和批次间隔，可停止队列。
7. 保存日志会显示成功/失败；文件存入浏览器默认下载目录下的“批量保存网页”子目录。

安装（Chrome / Edge）
1. 解压 ZIP 到固定文件夹。
2. 打开 chrome://extensions/ 或 edge://extensions/。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压目录中的 chrome-edge 文件夹。
5. 点击扩展图标打开工具页。

安装（Firefox）
1. 解压 ZIP。
2. 打开 about:debugging#/runtime/this-firefox。
3. 点击“临时载入附加组件”，选择 firefox 文件夹中的 manifest.json。
4. 临时附加组件可能在关闭浏览器后失效，需要重新载入。

保存到桌面
扩展将文件保存到浏览器默认下载目录中的“批量保存网页”子目录。若要放在桌面，请先在浏览器下载设置中把默认下载位置设为桌面，并关闭“下载前询问每个文件的保存位置”。

识别建议
- 从网页前台复制文章列表后，优先直接粘贴到“富文本编辑区”，点击“提取链接”。即使页面只显示标题，只要复制时保留了超链接，工具就能读取 href。
- 若粘贴后提取不到链接，切换“HTML 源码”区域，把含有 <a href="..."> 的源码粘贴进去，再点击“从 HTML 源码提取”。
- 默认只保留 .html 文章链接，域名默认为 2468c.com。若你的链接格式不同，请修改域名或“链接类型”。

限制与注意事项
- 只保存网页当前 DOM/HTML 快照，不会把图片、CSS、字体等外部资源打包进文件。
- 页面需要登录、验证码、动态授权或受到反爬限制时，可能保存失败或只能保存验证页。
- 首次保存可能请求访问链接所在网站的权限。请只授权你信任的网站，仅保存你有权访问和保存的内容，并合理控制访问频率。
